# SCL API Credit Dashboard — Owner Brief

Open **Admin → API Credits**.

## What to check first

1. Review **Used today, week, and month**, **Provider remaining**, and the monthly projection.
2. Use **Credits by sport/purpose** and **League pick demand** to see where credits create the most value.
3. Resolve any red limit warning before activating owner-managed scheduling.

## How to control spend

- **Guardrails:** Set daily, weekly, monthly, and per-run limits. Keep a protected reserve for results and verification.
- **Sports & markets:** Enable only the sports, leagues, and market groups SCL needs. Expanded markets and shorter refresh times cost more.
- **Verification:** Set separate daily request/credit limits and a reuse window. A longer reuse window reduces repeat checks.
- **Verification schedules:** Choose a whole slate or a soccer/tennis league, then run it once or repeat it on selected days and Eastern time.

## Safe activation

1. Leave **Owner-managed scheduling** off while reviewing settings.
2. Turn it on with **Pause optional API pulls** still enabled and save.
3. Run a **Dry run** for one sport and confirm the estimate.
4. Remove the pause only when the estimate and limits look right.

## Confirm it worked

Check **Activity & change history** for status, estimated versus actual cost, and any guardrail block. Pausing optional pulls does not stop results grading or cached odds boards.
