## Honest launch dependencies

- Production records, package evidence, CLV, and accolades depend on actual
  database data. The UI intentionally shows unavailable states instead of
  inventing statistics for ghost or zero-history cappers.
- External mailboxes and DNS aliases must be provisioned with the domain/email
  provider; application code can route a configured address but cannot create
  the mailbox.
- Winible/Whop checkout remains third-party. SCL stores reviewed package data
  and tracking links; it does not claim a live API synchronization where none
  exists.
